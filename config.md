# Химический новостной радар — конфиг (v4, облачная версия)

Источник правды для ежедневного автогенератора. Департамент международного развития
АО «Росхим». Работает как Claude Code Routine на облачной инфраструктуре Anthropic —
не зависит от того, включён ли локальный Мак. Доставка — **черновик письма в Gmail**
(создаёт Claude через Gmail MCP-коннектор; отправка — вручную, кнопкой «Отправить»).

## Цель и доставка

Каждое рабочее утро собрать сводку наиболее важных **свежих** (за ~24–72 ч) новостей,
влияющих на спрос/предложение/цены химии, сгенерировать файлы в `./out/`:
- `ДайджестРХ-<ДД-ММ-ГГГГ>.pdf` и `ДайджестРХ-<ДД-ММ-ГГГГ>.html` — архивная копия выпуска
- стабильные копии `ДайджестРХ-latest.pdf` / `ДайджестРХ-latest.html`
- `digest-email.html` / `digest-email.txt` — email-safe версия контента (только инлайн-стили,
  без `<style>`/CSS-переменных — Gmail их срезает) для черновика

PDF по SMTP не уходит: облачная песочница блокирует «сырые» TCP-сокеты вне HTTPS-прокси
(любой SMTP — Gmail, Outlook — падает одинаково), поэтому `build.py` почту не отправляет,
только готовит `digest-email.*`. Дальше Claude сам создаёт черновик в Gmail
(`mcp__Gmail__create_draft`: `to` из `DIGEST_RECIPIENTS`, `body`/`htmlBody` — содержимое
digest-email.txt/.html). У Gmail-коннектора нет вложений и нет отправки — только черновик;
PDF в письмо не попадает, остаётся архивной копией в `./out/` репозитория.
`./out/` живёт только внутри контейнера запуска, поэтому именно `digest-email.*` — то, что
реально долетает до получателей (через черновик, руками пользователя).

Схема: **LLM собирает контент в `issue.json` → `build.py` рендерит HTML и PDF** (так они
всегда согласованы; PDF — reportlab + Arimo (открытый метрический аналог Arial от Google),
кириллица и стрелки ↑↓→▲▼ без «квадратов», без цветных эмодзи; шрифт открытый — SIL OFL,
лежит в `fonts/` репозитория).

## Разделение ответственности (важно)

**Агент отвечает только за содержание и даты.** Всё остальное задаёт код `build.py` —
и переопределить это из `issue.json` нельзя:

| Что | Кто задаёт |
|---|---|
| `date_iso`, `date_human` | код (системная дата; расхождение — предупреждение в логе) |
| набор/порядок/номера/названия рубрик, эмодзи | код (`SECTION_SPEC`) |
| набор карточек регионов, флаги, роли | код (`REGION_SPEC`) |
| `age` (чип возраста) | код — считается из `pub_date`/`event_date` |
| `impact_label` | код — из `impact` (hi/med/watch) |
| подпись «обновлено» у трендов | код — из `trends.json → updated_iso` |
| дозапись `history.jsonl` | код — только по тому, что реально попало в выпуск |
| **содержание, ссылки, `pub_date`/`event_date`, `impact`, `dirs`, теги** | **агент** |

Агенту НЕ нужно писать: `age`, `impact_label`, `num`, `emoji`, `toc`, `date_human`,
и НЕ нужно вручную дописывать журнал.

## Пайплайн одного прогона

1. Определить сегодняшнюю дату и день недели.
2. Прочитать журнал `./history.jsonl` (освещённое за ~14 дней) — коммитится в репозиторий
   предыдущим запуском.
3. Собрать новости WebSearch/WebFetch по пулу запросов (см. ниже) с **правилами свежести**.
4. Собрать `./issue.json` по схеме (ниже). Тренды — в `trends.json`
   (обновлять только по понедельникам, см. «Тренды»); в `issue.json` их дублировать не нужно.
5. Запустить: `python3 build.py` → файлы появятся в `./out/`, включая `digest-email.html/.txt`.
6. **Прочитать вывод build.py** — он печатает отброшенное с причинами, счётчик по рубрикам,
   предупреждения и контент/адресатов будущего черновика. Если рубрики опустели — вернуться
   к п.3 и доискать свежее. Журнал код допишет сам.
6.5. Если `DIGEST_RECIPIENTS` задан — создать черновик в Gmail (`mcp__Gmail__create_draft`) из
   `digest-email.txt`/`.html`, получатели из `DIGEST_RECIPIENTS`. Отправка — вручную пользователем.
   Если не задан (build.py предупредил об этом на п.6) — шаг пропускается, черновик не из чего собирать.
6.6. Выслать PDF выпуска (`./out/ДайджестРХ-<ДД-ММ-ГГГГ>.pdf`) в чат прогона через `SendUserFile`
   с `display: "render"`. Делается каждый прогон и не зависит от п.6.5: вложений в письме нет,
   `./out/` живёт только внутри контейнера, поэтому в чате PDF — единственный способ увидеть выпуск.
7. Закоммитить и запушить в свою рабочую ветку обновлённые `history.jsonl`/`trends.json`/`issue.json`,
   чтобы следующий запуск видел актуальное состояние (подробности — в SKILL.md, шаг 7).

Полезные ключи: `--dry-run` (проверить, ничего не записывая), `--asof=ГГГГ-ММ-ДД`
(пересобрать выпуск задним числом).

Артефакт claude.ai в пайплайн НЕ входит (URL нестабилен, доступ только по VPN).

## Продуктовый watchlist (приоритет отбора — периметр «Росхим»)

- **Содовый кластер:** сода кальцинированная, сода пищевая (бикарбонат натрия),
  сульфат натрия.
- **Хлорно-щелочной кластер:** ПВХ (в т.ч. эмульсионный), хлор, каустическая сода,
  гидроксид калия, соляная кислота.
- **Индустриальный кластер:** борная кислота, диоксид титана, бутиловый ксантогенат,
  продукты переработки этилена (стирол и т.п.).
- **Агробиохимический кластер:** кормовые аминокислоты, пищевые добавки, удобрения и
  мелиоранты (в первую очередь карбамид, NPK, сероуглерод).
- **Нефтегазохимия:** метанол, олефины, топливо, каучуки (изопреновые,
  бутадиен-стирольные), ароматика.

**Плюс широкий охват** — любые крупные события по химии/удобрениям/энергетике/торговле,
влияющие на рынок, даже вне списка выше.

## Рубрики (порядок фиксирован; раздел «Ценовые сигналы» убран — у отдела есть котировки)

1. ⚡ Срочное / высокое влияние — 2–5 главных событий за сутки (мировых и российских).
2. 🌍 Геополитика и международная логистика — конфликты, торговые пути (Ормуз, Красное море,
   Панама, Малакка), фрахт, страховки, порты.
3. 🏭 Зарубежные мощности и производства — пуски/закрытия/расширения, ремонты, аварии,
   форс-мажоры **вне РФ**.
4. ⚖️ Зарубежное регулирование и санкции — пошлины/квоты, антидемпинг, санкции
   (OFAC/EU/BIS/UK), REACH/экология, торговые барьеры **вне РФ**. Санкции третьих стран
   ПРОТИВ России — это тоже сюда: регулятор иностранный.
5. 🛢️ Мировая энергетика и сырьевые рынки — нефть/газ/электроэнергия, фидстоки
   (нафта, этан, метанол).
6. 🇷🇺 Российский рынок — всё то же самое, но на уровне внутреннего рынка РФ: решения
   правительства/Минпромторга/Минэнерго, экспортные пошлины, квоты и запреты РФ, M&A,
   инвестпроекты, пуски и ремонты российских мощностей, логистика РЖД/портов РФ.
7. 📍 Новости по регионам — карточки: Китай/ЛатАм/Африка/MENA (детально) + Европа/Сев. Америка.
8. 📈 Тренды мировой химотрасли за месяц — обзор 3–5 трендов; из `trends.json`.

**Разделение РФ / не-РФ (проверяется кодом).** Новости внутреннего российского рынка идут
только в рубрику 6 — и, при высокой значимости, дополнительно могут попасть в рубрику 1
«Срочное». В рубриках 2–5 их быть не должно: `build.py` находит их по маркерам
(`RU_MARKET_RE`: Минпромторг, Минэнерго, правительство РФ, кабмин, Госдума, ФАС/ФТС России,
Ростехнадзор, РЖД, Новак, Мишустин, постановление правительства и т.п.) и **автоматически
переносит в «Российский рынок»**, печатая об этом предупреждение. Не полагайся на автоперенос —
раскладывай сам, маркеры покрывают не всё.

## Правила свежести и антиповтора

⚠️ **ГЛАВНОЕ: правила проверяются кодом, а не доверием к промпту.** `build.py` молча
выбрасывает всё, что им не соответствует, и печатает отчёт. Если не проставить даты —
пункт просто не попадёт в выпуск.

- **`pub_date` (ISO, обязательно у каждой новости, каждого буллета РЕГИОНА со ссылкой и
  каждой плитки тикера)** — реальная дата публикации источника. **Проверяй её у самого
  источника** (WebFetch статьи, если в выдаче поиска даты нет). НЕ угадывать и НЕ считать
  «свежим» то, что просто попалось в поиске: выдача регулярно отдаёт материалы месячной и
  годовой давности.
- **`event_date` (ISO, опционально)** — если новость это само событие, а статья вышла
  раньше (пошлина вступает в силу, старт ремонта, закрытие тендера). Свежесть считается по
  более поздней из двух дат.
- **Дата в будущем = отброс.** Поставить завтрашнее число, чтобы «пройти» фильтр, нельзя.
- **Окна:** новостные рубрики 1–6 — не старше **3 дней** (`MAX_AGE_NEWS_DAYS`); буллеты
  карточек регионов — **30 дней** (`MAX_AGE_REGION_DAYS`); плитки тикера — **2 дня**
  (`MAX_AGE_TICKER_DAYS`).
- **Новость без `source_url` отбрасывается.** Утверждение без ссылки в новостные рубрики
  не попадает.
- **Блок-лист «вечнозелёных» витрин отчётов — в коде** (`BLOCKED_DOMAINS`: imarcgroup,
  mordorintelligence, procurementresource, expertmarketresearch, marketreportsworld,
  coherentmarketinsights, price-watch, chemtradeasia, marketdataforecast,
  evolvancemarketresearch, intellectia, papaverai, grandviewresearch, marketsandmarkets,
  researchandmarkets, precedenceresearch, blackridgeresearch, futuremarketinsights,
  fortunebusinessinsights). Приоритет — датированным материалам лент и пресс-релизам.
- **Антиповтор проверяется кодом:** если URL или (нормализованный) заголовок уже были в
  выпусках за 14 дней — пункт отбрасывается. Провести долгий сюжет (Ормуз, санкции) можно
  ТОЛЬКО с `"update": true` и только при новой вехе — тогда в выпуске появится метка
  «Обновление».
- **Карточки регионов тоже под контролем.** Буллет со ссылкой обязан иметь `pub_date`.
  Буллет БЕЗ ссылки трактуется как аналитический синтез (даты не требует) — используй это
  для обобщений, а не чтобы протащить старую новость.
- **Тихий день:** если по рубрике за сутки реально ничего нет — `items: []`
  (рендер напишет «Существенных событий за сутки нет»). **Пустая рубрика лучше, чем
  несвежий пункт.**
- **Полностью пустой выпуск не собирается** — build.py выходит с ошибкой и НЕ перезаписывает
  вчерашние файлы. Это сигнал доискать события, а не ослаблять правила.

## Тикер (операционные сигналы, НЕ цены продуктов)

4–5 плиток: Brent, статус Ормуза, статус Красного моря, число крупных форс-мажоров за
неделю, при необходимости — энергия/газ или ключевой санкц. режим. Поле `dir`: `up`
(красный — стресс/рост), `down` (зелёный — снижение цены/риска), `flat` (нейтрально).
**У каждой плитки обязателен `pub_date`** — дата, на которую верно значение (не старше 2 дней).

## Тренды (месяц)

Файл `./trends.json`:
`{"updated_iso":"ГГГГ-ММ-ДД", "points":[{"title":"...","text":"..."}]}`.
**Обновлять полностью только по понедельникам** (или если файла нет / он старше 7 дней) —
пересобрать 3–5 ключевых трендов месяца по обзорным материалам и переписать `updated_iso`.
В остальные дни — не трогать. Код сам подставит тренды в выпуск и предупредит, если файл
залежался.

## Схема issue.json

```
{
 "date_iso":"ГГГГ-ММ-ДД",           // сверяется с системной датой
 "regions_line":"Китай · ЛатАм · Африка · MENA + ЕС/США",
 "ticker":[{"k":"Brent","v":"~$94","d":"▲ +3,4% за сутки","dir":"up",
            "pub_date":"2026-07-23"}, ...],
 "sections":[  // ровно 6 рубрик с id: urgent, geo, capacity, reg, energy, ru
   {"id":"urgent",
    "items":[{"impact":"hi|med|watch",
              "dirs":["Предложение ↓", ...],       // свободные подписи-чипы
              "update":false,                       // true только для новой вехи долгого сюжета
              "pub_date":"2026-07-22",              // ОБЯЗАТЕЛЬНО, проверено у источника
              "event_date":"2026-07-22",            // опционально: когда событие произошло
              "title":"...","why":"...",
              "regions":["MENA", ...],"products":["Нафта · СУГ"],
              "source_name":"CNBC","source_url":"https://..."}]},   // ссылка обязательна
   ... (geo, capacity, reg, energy, ru)
 ],
 "regions_cards":[{"name":"Китай",                  // имена строго: Китай, ЛатАм, Африка,
                   "bullets":[                      // MENA, Европа, Сев. Америка
                     {"text":"...","url":"https://...","pub_date":"2026-07-06"},
                     {"text":"обобщение без ссылки — даты не требует","url":""}]}, ...]
}
```

Поля `num`, `emoji`, `toc`, `title` рубрик, `flag`/`role` регионов, `age`, `impact_label`,
`date_human` задаются кодом — в issue.json их писать не нужно (будут проигнорированы).
Ссылки — в `source_url` / `bullets[].url`. Эмодзи только в HTML — в PDF срезаются
автоматически. Язык — русский.

## Логика отбора

Ранжировать по влиянию на спрос/предложение/цену химии; дубликаты схлопывать в один пункт с
лучшим источником; шум отсекать. Особый приоритет — продукты периметра «Росхим» и
санкции/барьеры по российскому химэкспорту. Цель — короткий actionable дайджест.
